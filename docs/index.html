装成 Skill（推荐）

把文件夹放进助手的 skills 目录，之后直接说一句话就行，不用记任何命令。

帮我把这门课的资料都下载下来，
课程链接：lms.xjtu.edu.cn/course/<课程ID>/index

助手会走完登录、列清单、等你确认、下载、按章归类。使用边界写在 SKILL.md 里，装成 Skill 不会绕过这些约束。

WorkBuddy~/.workbuddy/skills/xjtu-siyuanxuetang-grab/
Claude Code~/.claude/skills/xjtu-siyuanxuetang-grab/
Codex~/.codex/skills/xjtu-siyuanxuetang-grab/

不装 Skill 也能用

两条替代路径，都不需要助手支持 Skill 机制。

Prompt · 贴进任意对话式 AIprompt.md
命令行 · 自己控制每一步python scripts/lms_fetch.py ...

此时 SKILL.md 相当于一份完整操作手册，prompt.md 是可复制的通用 Prompt。

命令行用法

登录只需做一次，之后反复跑都会自动跳过已下载的文件。

pip install playwright

python scripts/lms_selfcheck.py --course <课程ID>
python scripts/lms_login.py --course <课程ID>

python scripts/lms_fetch.py --course <课程ID> --out "./课程资料" --dry-run
python scripts/lms_fetch.py --course <课程ID> --out "./课程资料"

加 --organize 就按章分好文件夹。录像动辄几百 MB，只要讲义就加 --no-video。

录像有两种

名字里都带「视频」，但承载方式完全不同，脚本两类都能下。

课堂录像 · online_video 就是普通附件，和课件同一个端点，几十 MB
直播回放 · lecture_live 独立录播系统，单节几百 MB，支持断点续传与双机位

回放默认只下「屏幕录制」机位；加 --all-cameras 连教师机位一起下。

使用范围

仅用于个人学习过程中的课程资料备份与离线整理，只访问当前登录账号正常拥有访问权限的课程资源。

会绕过认证或越权吗？ 不会。登录由学校统一身份认证完成，程序沿用你本人正常登录后的会话状态，也不提供枚举无权课程的功能。
会不会给平台造成压力？ 请求保持串行，权限类错误（401 / 403）立即停止重试，并支持断点续传避免重复下载。建议先用 --dry-run 确认资源量。
下载的资料可以再传播吗？ 不建议。课程资源版权归教师和学校，请在获得授权的范围内使用，不要通过本项目重新公开传播。

常见问题

干跑出来的清单不全？ 课件藏在活动正文里，不在附件字段。脚本已经两个来源都扫了，如果还缺，多半是平台侧无权限（会标 N/A）。
登录态多久过期？ 没有固定时限。下载前会自动探测，过期会明确提示重跑登录。
能用于别的学校吗？ 可以。用 --base 指向其他 TronClass 平台，同样仅限该账号有权访问的资源。
回放下载中途报错怎么办？ 直接重跑，从断点继续。回放地址在下载前才现取，中途遇到凭据过期会自动重新解析一次；回放请求需保持串行，并发会被服务端拒绝。
同一天上了好几节课，会覆盖吗？ 不会。文件名带本地时间戳，同名的多节课会各自留存。

特点

断点续传中断了从断点继续，不重头下
自动重试超时和 5xx 退避重试，权限错误不重试
按章归类认得出六种章号写法
串行请求不并发，避免给平台造成额外压力
课件·作业·录像·回放四类自动分流到各自目录
完整性校验sha256 + 大小交叉验证，支持增量

装完先自检

装好后第一次使用前跑一次自检。它把「环境没装好」和「平台没给权限」分开报——不然后者常伪装成前者，排查会很费时间。

python scripts/lms_selfcheck.py --course <课程ID>

默认只做离线检查，不碰服务端。加 --online 才顺带确认登录态在服务端是否仍然有效。

检查项Python 版本 · 脚本完整性 · playwright · 浏览器 · 缓存目录 · 登录态形状 · 浏览器 profile
分级✓ 通过 · ! 警告（不影响主链路）· ✗ 失败（必须先修）
修复提示每个不正常项都附一条可直接复制的命令
退出码0 无失败项 · 1 有失败项，可串进脚本或 CI

登录态检查能区分五种情况：文件不存在 / 文件损坏 / cookies 为空 / cookie 域不匹配 / 正常。它们的修法不同，所以不合并成一句「登录态有问题」。

自检报 ✗ 时先修完再往下走——带着坏环境去登录或下载，报出来的错会指向错误的方向。

为什么装成 Skill

脚本要记参数、记顺序、记端点；Skill 只要说一句话。助手会自己判断该干什么。

什么都不用配 文件夹放进 skills 目录即可，不需要额外安装步骤，也不需要把命令抄进对话。
自动匹配场景 说到「下载这门课的课件」「把课上资料拉下来」时，助手会自动读取并按流程执行。
边界跟着一起走 使用边界写在 SKILL.md 里，助手执行时会读到并遵守，不会绕过。
跨工具通用 SKILL.md 是通用格式，任何支持该约定的助手都能用，换工具不用改内容。
装完先自检 一次自检把环境问题和权限问题分开报，每项都给可复制的修复命令，默认不联网。

这一版装的是什么

仓库本身就是可直接放进 skills 目录的文件夹，不需要再打包或转换格式。

Skill 入口SKILL.md —— 流程、边界、注意事项
脚本scripts/ —— 自检 / 登录 / 下载 / 归类 / 回放
离线测试tests/ —— 387 个用例，不需要网络
替代用法prompt.md —— 贴进对话的通用 Prompt

也可以用 Release 里的 zip 包，解压后同样是这个文件夹结构。
