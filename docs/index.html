把整门课的课件、作业和录像

西安交大思源学堂 2.0 任意课程，自动走完登录、列清单、下载、按章归类。课堂录像与直播回放一并支持。

Python 3.8+ MIT 断点续传 · 双机位回放
下载 GitHub

用法

三步。登录只需做一次，之后反复跑都会自动跳过已下载的文件。

pip install playwright

python scripts/lms_login.py --course <课程ID>

python scripts/lms_fetch.py --course <课程ID> --out "./CV" --dry-run
python scripts/lms_fetch.py --course <课程ID> --out "./CV"

加 --organize 就按章分好文件夹。录像动辄几百 MB，只要讲义就加 --no-video。

录像有两种

名字里都带「视频」，但承载方式完全不同，脚本两类都能下。

课堂录像 · online_video 就是普通附件，和课件同一个端点，几十 MB
直播回放 · lecture_live 独立流媒体系统，单节 350–440 MB，支持断点续传与双机位

回放默认只下「屏幕录制」机位；加 --all-cameras 连教师机位一起下。

常见问题

干跑出来的清单不全？ 课件藏在页面正文里，不在附件字段。脚本已经两个来源都扫了，如果还缺，多半是平台侧无权限（会标 N/A）。
登录态多久过期？ 没有固定时限。下载前会自动探测，过期会明确提示重跑登录。
能下别的学校吗？ 可以。用 --base 指向任意 TronClass 平台。
回放下载中途报错怎么办？ 直接重跑，从断点继续。回放限流返回的 403 会被自动识别成限流并退避重试，不是登录态过期。
同一天上了好几节课，会覆盖吗？ 不会。文件名带本地时间戳，同名的多节课会各自留存。

特点

断点续传中断了从断点继续，不重头下
自动重试超时和 5xx 退避重试
按章归类认得出六种章号写法
可换学校指向任意 TronClass 平台
课件·作业·录像·回放四类自动分流到各自目录
多机位命名带本地时间戳，同名课程不会互相覆盖

装成 Skill

把文件夹放进对应目录，之后直接跟 AI 说「帮我把这门课的课件和录像都下载下来」就行。

WorkBuddy~/.workbuddy/skills/xjtu-siyuanxuetang-grab/
Claude Code~/.claude/skills/xjtu-siyuanxuetang-grab/
Codex~/.codex/skills/xjtu-siyuanxuetang-grab/

不装也能用，脚本是独立的命令行工具。
