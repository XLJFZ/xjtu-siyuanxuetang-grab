把整门课的课件和作业
一次性拉到本地

西安交大思源学堂 2.0 任意课程，自动走完登录、列清单、下载、按章归类。

Python 3.8+  ·  MIT  ·  实测 58 个文件 / 530 MB / 0 失败
下载 GitHub

用法

三步。登录只需做一次，之后反复跑都会自动跳过已下载的文件。

pip install playwright

python scripts/lms_login.py --course <课程ID>

python scripts/lms_fetch.py --course <课程ID> --out "./CV" --dry-run
python scripts/lms_fetch.py --course <课程ID> --out "./CV"

加 --organize 就按章分好文件夹。

特点

断点续传中断了从断点继续，不重头下
自动重试超时和 5xx 退避重试
按章归类认得出六种章号写法
可换学校指向任意 TronClass 平台

装成 Skill

把文件夹放进对应目录，之后直接跟 AI 说「帮我把这门课的资料下载下来」就行。

~/.workbuddy/skills/xjtu-siyuanxuetang-grab/
~/.claude/skills/xjtu-siyuanxuetang-grab/
~/.codex/skills/xjtu-siyuanxuetang-grab/

不装也能用，脚本是独立的命令行工具。
